# Getting started · compatibility documentation path

This `.zh.md` path is retained to avoid breaking earlier links in the English repository. The current English instructions are [GETTING_STARTED.md](GETTING_STARTED.md).

Use [surge-V3.0.0.conf](../profiles/surge-V3.0.0.conf). It sets `ipv6 = false` and has no public node definitions. Add your own nodes and resolve the explicit fallback member labels before use. Older v6.x module/subscription instructions are historical.

For Chinese documentation, visit the [canonical Chinese repository](https://github.com/dalao-all/Surge-Diversion-Rules).
